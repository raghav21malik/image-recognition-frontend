Academic Research
Research & Academic Background
Each model represents a milestone in the evolution of computer vision. From pioneering CNNs to revolutionary Transformers, these architectures have shaped how machines understand visual data.
🔵
ViT-Base/16
Vision Transformer · Google (2020)
"An Image is Worth 16×16 Words: Transformers for Image Recognition at Scale"
Authors: Dosovitskiy et al. (Google Research)
Venue: ICLR 2021 · arXiv:2010.11929 ↗
Key Innovation
First successful application of a pure Transformer to image classification. Demonstrated that when pre-trained on large datasets (ImageNet-21k, JFT-300M), Vision Transformers can match or exceed CNNs without any convolutional layers.
85.8% Top-1 on ImageNet (pre-trained on ImageNet-21k)
🟢
ResNet-50
Residual Network · Microsoft (2015)
"Deep Residual Learning for Image Recognition"
Authors: He et al. (Microsoft Research)
Venue: CVPR 2016 (Best Paper Award) · arXiv:1512.03385 ↗
Key Innovation
Introduced skip connections (residual learning) that solved the degradation problem in very deep networks. Enabled training of networks with 100+ layers by allowing gradients to flow directly through shortcut connections.
80.8% Top-1 on ImageNet-1k
🟢
MobileNet-V2
Depthwise Separable CNN · Google (2018)
"MobileNetV2: Inverted Residuals and Linear Bottlenecks"
Authors: Sandler et al. (Google)
Venue: CVPR 2018 · arXiv:1801.04381 ↗
Key Innovation
Introduced inverted residual blocks with linear bottlenecks optimized for mobile devices. Depthwise separable convolutions reduce computation by 8-9× compared to standard convolutions while maintaining competitive accuracy.
71.8% Top-1 on ImageNet-1k (only 3.4M parameters)
🩷
Swin-Tiny
Shifted Window Transformer · Microsoft (2021)
"Swin Transformer: Hierarchical Vision Transformer using Shifted Windows"
Authors: Liu et al. (Microsoft Research Asia)
Venue: ICCV 2021 (Best Paper Award) · arXiv:2103.14030 ↗
Key Innovation
Replaced global self-attention with shifted window attention, reducing computational complexity from quadratic to linear. Produces hierarchical feature maps like CNNs, making it suitable for dense prediction tasks (detection, segmentation).
81.3% Top-1 on ImageNet-1k
🟡
DeiT-Base
Knowledge Distillation Transformer · Meta / Facebook (2020)
"Training Data-Efficient Image Transformers & Distillation through Attention"
Authors: Touvron et al. (Meta / Facebook AI)
Venue: ICML 2021 · arXiv:2012.12877 ↗
Key Innovation
Showed that Vision Transformers can be trained effectively on ImageNet-1k alone (without ImageNet-21k) using strong data augmentation and knowledge distillation. Introduced a distillation token that learns from a CNN teacher through attention.
83.4% Top-1 on ImageNet-1k (with distillation from RegNet teacher)
Comparative Analysis
CNN vs Transformer: The Paradigm Shift
The evolution from CNNs to Vision Transformers represents a fundamental paradigm shift in computer vision. Traditional CNNs like ResNet-50 rely on local receptive fields — each layer only sees a small neighborhood of pixels, building global understanding through depth. Vision Transformers like ViT flip this paradigm: every patch attends to every other patch from layer one, capturing global relationships immediately.
This project deliberately selects models spanning this entire spectrum: ResNet-50 (pure CNN, 2015) → MobileNet-V2 (efficient CNN, 2018) → ViT (pure Transformer, 2020) → DeiT (data-efficient Transformer, 2020) → Swin (efficient hierarchical Transformer, 2021). This allows direct comparison of how different architectural philosophies handle the same visual input.
Aspect CNN Approach Transformer Approach
Receptive Field Local → Global (via depth) Global from layer 1
Inductive Bias Translation equivariance Minimal (learned)
Data Efficiency Strong with small data Needs large data (or distillation)
Compute Scaling Sub-quadratic Quadratic (or windowed)
Feature Hierarchy Built-in (via pooling) Requires design (e.g., Swin)

Why This Exists
Problem & Solution
A real-world challenge solved with cloud AI infrastructure.
⚠️
Problem Statement
Manual Image Identification
Manual image identification is slow, inconsistent, and error-prone at scale. Humans struggle to classify thousands of images accurately and quickly, and there's no structured way to store, search, or revisit those results.
✅
Solution
AI-Powered Cloud Pipeline
An AI-powered cloud application that automatically analyzes uploaded images, classifies content using Vision AI, stores results in cloud storage, and maintains a searchable scan history — all in real time with zero manual effort.
